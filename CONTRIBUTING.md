# Contributing to Freshness Reference

Contributions are welcome through pull requests or at hello@scotf.org.

## Principles
- Open standards first. Follow the published GS1 and industry specifications this repository references, and cite the version used.
- Specification first: change the schema or API definition, then the code, then the docs.
- Tests first. Every change ships with tests; the suite must pass before a pull request.
- Neutrality: describe roles and open standards, not products. Name a company only with its approval. Listing a company, product or tool is not an endorsement.
- No real company data. Examples and test fixtures use synthetic data.

## Licensing
- Code: Apache License 2.0; keep the NOTICE file.
- Documentation: CC BY-NC 4.0 unless a file states otherwise.
- Attribution in code and commits follows `docs/ATTRIBUTION.md`.

## Before opening a pull request
Run the full test suite and update the README quick start if behavior changed.
